## D09 - Kubernetes Basics

Основы оркестрации контейнеров с использованием Kubernetes. Проект охватывает развёртывание микросервисного приложения через собственноручно написанные манифесты, работу с ConfigMap и Secrets, а также применение стратегий обновления.

### О проекте

Проект посвящён изучению Kubernetes как платформы для оркестрации контейнеров. На первом этапе было развёрнуто готовое приложение из предоставленного манифеста. На втором этапе с нуля написаны собственные манифесты для микросервисного приложения: настроены ConfigMap и Secrets, описаны Pods и Services для PostgreSQL, RabbitMQ и семи микросервисов. Проведено тестирование через Postman, изучены стратегии обновления приложения (Recreate и Rolling Update) с замером времени переразвёртывания.

Работа выполнялась в среде Minikube.

### Ключевые навыки

В ходе выполнения проекта были освоены и применены следующие технологии и инструменты:

- **Kubernetes:** написание манифестов (YAML), работа с Pods, Services, ConfigMap, Secrets
- **Minikube:** развёртывание локального кластера, создание туннелей, работа с dashboard
- **kubectl:** применение манифестов, просмотр и диагностика объектов, чтение логов, декодирование Secrets
- **Postman:** функциональное тестирование API микросервисного приложения
- **Стратегии деплоя:** Recreate, Rolling Update, замер времени переразвёртывания

### Выполненные задачи

Проект состоит из двух частей:

1.  **Готовый манифест:**
    - Запуск окружения Kubernetes с 4 ГБ памяти.
    - Применение готового манифеста из `/src/example`.
    - Запуск Kubernetes dashboard и создание туннелей для доступа к сервисам.
    - Проверка работоспособности приложения через браузер.
2.  **Собственный манифест:**
    - Создание ConfigMap с хостами базы данных и сервисов.
    - Создание Secrets с паролями, логинами и ключами авторизации.
    - Описание Pods и Services для PostgreSQL, RabbitMQ и семи микросервисов.
    - Последовательное применение манифестов и проверка статуса объектов.
    - Декодирование Secrets и проверка логов контейнеров.
    - Создание туннелей и прогон функциональных тестов через Postman.
    - Изучение состояния кластера через Kubernetes dashboard.
    - Обновление приложения с применением стратегий Recreate и Rolling Update, замер времени переразвёртывания.

### Структура проекта

- `src/example/` — готовый манифест для Part 1
- `src/app/` — манифесты для микросервисного приложения (ConfigMap, Secrets, Pods, Services)
